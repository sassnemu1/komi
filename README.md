# komi.world — портал Республики Коми

Главный сайт экосистемы komi.world. Проект УК «Велес И К» (Сыктывкар,
info@komi.world) — холдинга, который владеет всем, что здесь показано: заводом
напитков «Велес» и его брендами, пекарней, мебелью, мехом, ювелиркой, техникой
YÖRAN, отелями и ресторанами, туристическим коридором Якша—Маньпупунёр и
фольклорной картой [map.komi.world](https://map.komi.world).

Продакшен: Vercel-проект `komi` (github.com/sassnemu1/komi → `komi-alpha.vercel.app`,
целевой домен komi.world). Пуш в `main` деплоит автоматически.

## Стек

Next.js 16 (App Router, Turbopack, React Compiler), React 19, CSS-модули, GSAP +
ScrollTrigger (подгружается динамически через `src/hooks/useGSAP.js`; reveal-on-scroll
нижних секций — `src/hooks/useReveal.js` по атрибуту `data-reveal`; скролл-параллакс
слоёв — `src/hooks/useParallax.js` по `data-parallax="N"` внутри `data-parallax-scope`),
Lenis (плавный скролл, `src/components/SmoothScroll`), react-icons.

```bash
npm install
npm run dev -- --port 3100   # в KOMI/.claude/launch.json это конфиг `komi-site`
npm run build
npx eslint src
```

## Карта районов

Официальные символы (проверка 06.09.2026: geraldika.ru, heraldicum.ru,
vexillographia.ru, Википедия, Commons; каждое положительное утверждение
подтверждали два независимых поиска): флаг утверждён у 9 из 19 муниципалитетов
на карте (Воркута, Инта, Ижемский, Княжпогостский, Койгородский, Корткеросский,
Печора, Сосногорск, Усть-Цилемский). У остальных десяти есть только герб —
восемь показаны гербом (Усинск, Ухта, Вуктыл, Сыктывдинский, Сысольский,
Троицко-Печорский, Усть-Вымский, Усть-Куломский), у Удорского и Прилузского
свободного изображения герба нет — только реквизиты в панели. Флаги никому не
дорисовываются: «Flag of Priluzsky District.png» на Commons — пользовательский
файл без официального источника, «Flag of Troitcko-Pechorsk» — флаг посёлка, не
района. Данные и ссылки на источники — `src/components/KomiMap/komiDistricts.js`.

`komiDistricts.js` — соответствие id путей SVG ⇄ район (совпадает с
`districts.js` на map.komi.world, менять синхронно). Клик по району открывает
`DistrictPanel`; данные панели:

- `districtFacts.js` — каждая цифра взята из инфобокса страницы в `source`
  (ru.wikipedia, оценка населения на 2025). Собрано 2026-09-06 и отдельно
  перепроверено агентом-скептиком: 19/19 совпали с источниками.
- `districtLore.js` — выжимка корпуса map.komi.world: `LORE_BY_DISTRICT[pathId]`,
  `LORE_AREA_WIDE`, `LORE_GENRES`, `loreEntryUrl(id)`, `loreDistrictUrl(pathId)`.
  Не править руками — `node scripts/sync-lore.mjs` после изменений корпуса.

Кнопка «Открыть район на карте преданий» ведёт на `map.komi.world/?district=<pathId>` —
карта преданий поддерживает этот параметр.

## Фотографии

Hero — сцена «три полосы, три стихии» (`HeroBackdrop`): фото тайги
Печоро-Илычского заповедника («Густой туман», Г. Новинская) как небо и дальний
план, три иллюстрации леса с прозрачным фоном (`public/photos/forest-{far,mid,
near}.webp`, материалы заказчика: дальний туманный ряд, средний лес с «окном» по
центру, ближний тёмный ряд) на разной глубине параллакса, а поверх — полупрозрачный
флаг Коми (#0039A6 · #009B3A · #FFFFFF при 0,62 / 0,58 / 0,78), полосы которого
тонируют сцену: небо в синь, тайгу в зелень, туман в белизну. Сверху — звёзды,
северное сияние и снегопад на canvas. Слои с `data-depth` едут за курсором на
разную глубину (ближний лес сильнее, заголовок навстречу); по скроллу лес
оседает и поднимается «ночь» (`data-layer="night"`), под которой раскрывается
карта — звёзды и сияние остаются над ней. Звёзды генерируются сидированным
PRNG, поэтому SSR и клиент совпадают. Слово «КОМИ.» набрано Manrope 800
(`--font-title`, next/font) — строгий гротеск; подпись и рельсы иконок на белой
полосе — чернилами.

`public/photos/` — 19 снимков с Wikimedia Commons (CC BY-SA 4.0 / CC BY 3.0 /
CC BY-SA 3.0): тайга в тумане, Якша, лосеферма, лесное озеро и коми-изба этнопарка
в Ыбе (Г. Новинская), зимняя тайга заповедника, Манарага и долина Манараги
(Aysa t), Маньпупунёр (А. Романов, Ввкстар, Asankheia), Печора, тропа через болото
(J. Metselaar), водопад на Хальмер-Ю (Malupasic), Печора с высоты (k0k00rt), Ухта с
высоты (Екатерина Борисова), тундра (APL) — плюс пять визуализаций из меморандума
УК «Велес И К» (`render: true`: лобби, домик, изба, купол глэмпинга, гондола
фуникулёра) для отелей и ресторанов, которых ещё нет в природе; на карточках они
помечены словом «визуализация» и в подвал как фото не попадают. Метаданные, alt-тексты и ссылки на
страницы файлов — в `src/data/photos.js`; авторы перечисляются в подвале
автоматически из `PHOTO_CREDITS`. Все фото отдаются через `next/image`,
исходники сжаты до 1600–2400 px. У каждого снимка есть
blur-плейсхолдер (`blur`, JPEG 24 px в data-URI) — его генерирует
`node scripts/gen-blur.mjs` (sharp из зависимостей Next) и вписывает в `photos.js`;
после замены фотографий скрипт нужно запустить снова.

Компонент `Interlude` — полноэкранная фото-интерлюдия между главами (две на
странице: тундра и долина Манараги) с многослойным параллаксом на scrub:
фото едет медленнее страницы (±15 % своей высоты, слой выше секции на 2 × 26 %)
и слегка наезжает при входе, текст идёт навстречу и проявляется в первой трети.
Пропы: `depth` (0…1, амплитуда; ~0.7 для кадров с людьми) и `focus="top"` —
на телефоне узкое окно показывает только середину высокого слоя, поэтому для
кадров с сюжетом у верхней кромки слой смещается вниз, а ход уменьшается.
Параллакс есть и у подложки «Кемпинга», фото Печоры в «Отелях» и плиток
«Впечатлений» (`useParallax`).

## Правила контента

- Факты о брендах, отелях, ресторанах и сервисах — только из README холдинга
  (`veles i k/`) и с собственных сайтов холдинга: завод напитков «Велес»
  (veles-site-kiselev.vercel.app — составы, форматы, сроки, завод в Химках,
  коллекция «Легенды России») и YÖRAN (yoran-web.vercel.app — линейка семи
  машин со сроками, экипировка, завод в Ухте; сайт помечен как прототип-
  концепция, поэтому сроки подаются как план). Чего там нет — на сайте нет
  (кухни ресторанов, звёзд отелей, цен за ночь).
- Факты о фольклоре — только из корпуса map.komi.world; каждая карточка мифологии
  ссылается на конкретную запись.
- Внешних картинок больше нет: все фото лежат в `public/photos` с атрибуцией.
  Снимки с Яндекс Карт и других сервисов не используем — их условия и авторские
  права не позволяют; у объектов холдинга, которых ещё нет, стоят его же
  визуализации из меморандума, у остальных — фото места с подписью.
- Никаких ссылок на домены экосистемы, которых ещё нет (madein, hotels, taxi…):
  живые внешние ссылки — map.komi.world, сайт завода «Велес» и сайт YÖRAN
  (досье «Сделано в Коми», глава «Холдинг», подвал).

## Технические заметки

- Перезагрузка страницы с пинами (`components/ScrollRestore`): браузерное
  восстановление скролла срабатывало до появления pin-spacer'ов и пересчёта
  Lenis — после перезагрузки страница «уезжала» в чужую секцию (на 5200 px
  оказывалась на 9996). Теперь `history.scrollRestoration = "manual"`, позиция
  пишется в sessionStorage, а возвращается после загрузки шрифтов, `load` и
  `ScrollTrigger.refresh()`. Там же — страховка reveal: всё, что через 2,5 с
  скрыто, но уже в кадре, показывается. `useReveal` не прячет элементы, которые
  в момент инициализации уже видны, и срабатывает один раз (`once`).
- Шрифты — next/font в layout.js: Bebas Neue, DM Sans и Manrope через
  `next/font/google` (self-hosted на сборке, с preload, без блокирующего
  `@import`), Ponomar — через `next/font/local` из `src/app/fonts/`
  (сабсет кириллица+латиница, woff2, SIL OFL 1.1 — лицензия рядом с файлом):
  у Google-варианта нет таблицы метрик в Next, и загрузчик писал
  «Failed to find font override values» на каждой сборке. Токены `--font-*`
  в globals.css ссылаются на переменные next/font.
- Пины ScrollTrigger («Места», гараж YÖRAN) закрепляют узел, у родителя
  которого нет других детей (`.pinned` внутри секции, `.garageWrap`):
  pin-spacer меняет DOM вне React, и если закреплён прямой ребёнок `<main>`,
  любая вставка соседа (смена мобильной/десктопной версии по ресайзу) падает
  с `NotFoundError: insertBefore`. Оба пина несут `refreshPriority`: чанки
  гидрируются в произвольном порядке, а GSAP учитывает pin-spacer соседей
  только у триггеров выше по списку — без сортировки по позиции нижний пин
  «парковался» на 2900px раньше.
- Тяжёлые главы (Landmarks, MadeInKomi, Transport) подключены через
  `next/dynamic`: HTML по-прежнему серверный, а их JS — отдельными чанками.
- Зима: `body::after` — иней по углам экрана (CSS, без JS); `SnowEdge` — снежные
  кромки между главами; снежинка в надзаголовках `SectionHead`; ховеры карточек
  инеем (`--frost`, `--ice`); в hero — луна, штрихи ветра, иней в углах рамки, передний сугроб с самым быстрым параллаксом,
  фон затемнён (brightness .76, полосы флага плотнее, виньетка).

- Плавный скролл — Lenis поверх нативного: сглаживает колесо/трекпад, touch
  остаётся нативным, при `prefers-reduced-motion` не включается. Кадры считает
  `gsap.ticker`, ScrollTrigger обновляется из `lenis.on("scroll")`. Экземпляр —
  `window.__lenis`: шапка скроллит через него (`lenis.scrollTo`, он сам учитывает
  `scroll-margin-top` цели), меню ставит `stop()/start()`. Вложенные скроллеры
  (панель района, легенда, меню) помечены `data-lenis-prevent`. Пока Lenis
  анимирует, `window.scrollTo` игнорируется — программный скролл только через него.
- Headless-проверка (Chrome через puppeteer-core, см. историю сессии): в
  видимом окне rAF идёт, поэтому замеры параллакса и скриншоты по позициям
  скролла надёжны; для мобильной раскладки — viewport 390×844 с touch.
- Скролл-лок оверлея слайдера — `overflow: hidden` на `<html>`, а не
  `body { position: fixed }`: последний обнулял `window.scrollY`, и ScrollTrigger
  разом снимал все пины.
- Вступление hero — CSS-анимация внутренних обёрток букв (~1 с), работает
  с первого кадра независимо от JS. GSAP в `useLayoutEffect` сразу создаёт
  скролл-таймлайн на внешних обёртках: ранняя прокрутка не ждёт вступления,
  поздняя гидратация не скрывает заголовок повторно. `gsap.context().revert()`
  очищает и стили, и ScrollTrigger при размонтировании / StrictMode.
  Кликабельность карты синхронизируется также после `refresh()`.
- Все три слоя леса hero предзагружаются и проявляются вместе после `decode`
  (через `next/image` onLoad). Ошибка отдельной картинки не блокирует другие
  слои. Фото тайги с blur-заглушкой и текст доступны во время загрузки.
  Фон нижней главы «Места» загружается лениво, не конкурируя с первым экраном.
- Видео такси играет через IntersectionObserver: ScrollTrigger переносит секцию в
  pin-spacer на каждом refresh, а Chrome ставит `<video>` на паузу при извлечении
  из DOM.
- `prefers-reduced-motion`: интро не играет, скролл-анимации — без scrub-задержки,
  секции с пином показывают статичные версии, видео не автоплеится.
- Проверка анимаций в браузере: Chrome останавливает rAF (и GSAP) в перекрытой
  другим окном вкладке — `document.visibilityState === "hidden"` при
  `hasFocus() === true`. Окно должно быть реально видно.
